# Инструкция по запуску 3D STL Telegram Бота 🚀

Этот бот автоматически находит популярные 3D-модели на **Printables** и **Thingiverse**, анализирует их изображения с помощью ИИ (Vision), составляет описание на русском языке и публикует в ваш Telegram-канал вместе с STL/ZIP файлом.

## 📋 Требования
1. **Python 3.10+**
2. **Токен Telegram Бота** (вы уже получили его у @BotFather)
3. **API Ключ OpenAI** (необходим для работы ИИ-зрения и перевода)
   * *Примечание: В скрипте используется модель `gpt-4o` для анализа фото.*

## 🛠 Установка

1. **Скачайте файлы**: Сохраните `3d_auto_poster.py` и `requirements.txt` в одну папку.
2. **Установите библиотеки**:
   Откройте терминал в этой папке и выполните:
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ Настройка
Откройте файл `3d_auto_poster.py` в текстовом редакторе и проверьте следующие строки:
* `TOKEN`: Ваш токен бота.
* `CHAT_ID`: ID вашего канала (например, `@TREEDSTL`).
* `OPENAI_API_KEY`: Убедитесь, что этот ключ установлен в вашей системе как переменная окружения, или вставьте его напрямую в код (не рекомендуется для безопасности).

## 🚀 Запуск

### Разовый запуск:
```bash
python 3d_auto_poster.py
```

### Автоматизация (10 раз в день):
Чтобы бот работал сам, используйте планировщик задач:

#### Для Windows (Планировщик задач):
Создайте задачу, которая запускает `python 3d_auto_poster.py` каждые 2 часа.

#### Для Linux (Cron):
Выполните `crontab -e` и добавьте строку для запуска каждые 2 часа (например):
```bash
0 */2 * * * /usr/bin/python3 /путь/к/файлу/3d_auto_poster.py
```

## 📂 Файлы в комплекте:
* `3d_auto_poster.py`: Основной код.
* `posted_models.txt`: База данных, чтобы не было дубликатов (создастся сама).
* `requirements.txt`: Список зависимостей.
